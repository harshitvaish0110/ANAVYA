# Anvaya v2

- All work for this project happens in `anvaya-v2/`. `anvaya-v1/` is reference only.
- Code: follow the **ponytail** plugin. Pick the simplest solution that works: YAGNI, stdlib first, no abstractions nobody asked for. Run `/ponytail-review` on changes before calling them done.
- UI: use the **ui-ux-pro-max** skill whenever you design or build any screen, component, palette, typography, or chart.
